# @sherif-fanous/pi-dracula

Dracula themes for the Pi Coding Agent. This package provides both the Dracula
and Alucard flavors as installable Pi themes.

## Install

```shell
pi install npm:@sherif-fanous/pi-dracula
```

Or try without installing

```shell
pi -e npm:@sherif-fanous/pi-dracula
```

Then select a theme via `/settings`.

## Uninstall

```shell
pi remove npm:@sherif-fanous/pi-dracula
```
